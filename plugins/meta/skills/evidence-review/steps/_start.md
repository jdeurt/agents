# Establish review inputs

## Purpose

Prepare the complete evidence node file for a candidate brief review.

## Inputs

- Candidate: the exact text to assess.
- Evidence: supplied observations, checks, and limitations relevant to that text.

## Instructions

Require both artifacts. Block if either artifact is absent. Keep the candidate and evidence separate so that a claim cannot serve as its own evidence.

## Outputs

- Candidate: the unchanged text to assess.
- Evidence: the unchanged supporting observations and limits.
